# Playbook

This is how to use HAIMM in practice, as distinct from `framework/`, which holds the model itself.

- `running-an-assessment.md`: scope, evidence access, sequence, reporting, known weaknesses.
- `acting-on-a-result.md`: what to do with a profile once you have one.

Two things have not been written yet: forms to record an assessment in, and a facilitation guide for running one as a workshop instead of as an audit. Both are deferred until the gates have been run against a real team at least once, because the format ought to follow what actually happens in the room. In the meantime, the gates themselves carry everything you need in order to run an assessment without them.
