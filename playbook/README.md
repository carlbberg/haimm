# Playbook

How to use HAIMM in practice, as distinct from `framework/`, which is the model itself.

- `running-an-assessment.md` — sequence, evidence access, reporting, known weaknesses.
- `instruments/` — generated checklists and survey forms. Do not edit; change `framework/gates/*.yaml` and run `python3 tools/generate.py`.

Not written yet: a facilitation guide for the workshop format, and guidance on what to do with a result once you have one. The second is the bigger gap. An assessment that names a gap and offers no next move is half a tool.
