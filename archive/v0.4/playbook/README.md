# Playbook

This is how to use HAIMM in practice, as distinct from `framework/`, which holds the model itself.

- `running-an-assessment.md`: scope, evidence access, sequence, reporting, known weaknesses.
- `acting-on-a-result.md`: what to do with a profile once you have one.

Two things do not exist yet: forms to record an assessment in, and a facilitation guide for running one as a workshop instead of an audit. We are deferring both until somebody has run the gates against a real team, because the format ought to follow what actually happens in the room. Meanwhile the gates carry everything you need to run an assessment without them.
