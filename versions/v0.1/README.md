# HAIMM v0.1

Published as an article on 24 December 2024. Frozen. This is the version of
record for v0.1, so that changes in later versions read as diffs against
something fixed.

```
article.md    the published text, verbatim, defects preserved
SOURCE.md     provenance, capture method, and the defects preserved
figures/      the four figures, with a rights note
VERSION       0.1.0
```

`article.md` is the model. `SOURCE.md` is how to trust it: what was captured,
what was repaired, and the six things known to be wrong or unresolved.

**Do not correct anything in this directory.** Corrections belong to the next
version. Three of the six known issues are citation problems, and two of those
need checking against a primary source before anything is rewritten anywhere.

## What v0.1 contains

Five stages: Exploration, Experimentation, Integration, Optimization,
Continuous Evolution.

Four dimensions: Solution Fit, Human-AI Collaboration, People, Ethics.
Knowledge & Context does not exist yet.

Each dimension is described at each stage with an example, and carries a
per-stage list of suggested metrics. There are no gates. v0.1 is descriptive,
so a team places itself and nothing in the model lets them fail a check.
