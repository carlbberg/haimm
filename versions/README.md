# Released versions

One folder per released version of HAIMM, frozen at release.

A version folder is never edited after its version is released. If something in
it is wrong, it stays wrong and gets corrected in the next version, so that the
correction reads as a decision rather than an edit. Each folder is
self-contained and free to have a different internal structure from the others,
because the model's shape changes between versions and forcing a single layout
on all of them would hide that.

| Version | Released | State |
|---|---|---|
| [v0.1](v0.1/) | 24 December 2024 | Published as an article. Frozen. |

The version in progress is not here. It lives at the repository root, and gets
snapshotted into this folder when it is released.

Files that describe the project rather than one version stay at the root:
the evidence log, open questions, the changelog, and the tooling. There is one
of each, and they cover all versions.
